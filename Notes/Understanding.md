# E-Commerce Transactions Dataset

A comprehensive synthetic e-commerce transaction dataset containing **71,772 individual orders** generated by **19,076 unique customers** across **six countries** between **9 January 2023 and 31 December 2024**. The dataset is designed to simulate a realistic online retail environment while maintaining high data quality and consistency, making it ideal for data analytics, business intelligence, SQL, Python, Power BI, Tableau, and machine learning projects.

Unlike many public datasets that require extensive preprocessing, this dataset has already been cleaned and validated. It contains **no missing values, no duplicate transactions, and verified revenue calculations**, allowing analysts to focus directly on business insights rather than data cleaning.

The dataset is particularly suitable for customer behavior analysis, cohort retention analysis, RFM segmentation, Customer Lifetime Value (CLTV) estimation, revenue forecasting, marketing attribution, and executive dashboard development.

# Dataset Schema

Each row in the dataset represents a **single completed customer transaction**.

| Column | Data Type | Description |
| :--- | :--- | :--- |
| **order_id** | String | Unique identifier assigned to each transaction (e.g., `ORD0000001`). No duplicate order IDs exist. |
| **customer_id** | String | Unique customer identifier (e.g., `CUST000001`). A customer may place multiple orders. |
| **transaction_date** | Date | Date on which the order was placed. Stored in `YYYY-MM-DD` format. |
| **product_category** | Categorical | Product category purchased in the transaction. Six categories are available. |
| **quantity** | Integer | Number of units purchased in a single order. Values range from **1 to 4**. |
| **unit_price** | Float | Selling price per unit, ranging between **$10.14** and **$249.99**. |
| **revenue** | Float | Total transaction value calculated as `quantity × unit_price`. |
| **signup_date** | Date | Customer registration date. Always occurs before or on the first purchase date. |
| **acquisition_channel** | Categorical | Marketing source through which the customer was acquired. Seven acquisition channels are represented. |
| **country** | Categorical | Customer's country. Six countries are included in the dataset. |

# Revenue Validation

A key strength of this dataset is its verified financial consistency.

For every transaction:

```text

```

A full validation across **71,772 transactions** confirms that the formula holds exactly for every record.

This guarantees reliable financial reporting and ensures that revenue-based analyses are free from computational inconsistencies.
