# SaaS/E-Commerce Cohort Retention & Customer Lifetime Value (CLTV) Analysis

## Overview

Customer retention is one of the most important drivers of long-term business growth. While acquiring new customers requires significant marketing investment, retaining existing customers improves profitability and sustainable revenue generation.

This project focuses on performing Cohort Retention Analysis and Customer Lifetime Value (CLTV) analysis using transactional customer data. The objective is to identify customer retention patterns, measure long-term customer value, and provide data-driven insights that support strategic business decisions.

This project is being developed as part of the **Data Analytics Technical Internship**.

---

## Business Problem

Organizations often invest heavily in customer acquisition without fully understanding customer retention behavior. Monitoring acquisition alone does not reveal whether customers continue engaging with the business over time.

This analysis addresses questions such as:

- How well are customers retained over time?
- Which customer cohorts exhibit stronger retention?
- How does customer value differ across various segments?
- What insights can support customer retention strategies?

---

## Project Objectives

- Perform comprehensive data cleaning and preprocessing
- Build monthly customer cohorts based on acquisition date
- Analyze customer retention across multiple periods
- Calculate Customer Lifetime Value (CLTV)
- Segment customers using business-relevant dimensions
- Develop clear visualizations to communicate retention trends
- Generate actionable business insights from analytical findings

---

## Dataset

The analysis is performed using a transactional dataset containing customer purchase activity and related business information.

Typical data includes:

- Customer ID

- Order Value
- Revenue
- Product Information

## Analytical Workflow

### Data Preparation

- Import datasets
- Inspect data quality
- Handle missing values
- Remove duplicates
- Standardize data types

### Cohort Analysis

- Calculate Cohort Month
- Assign customers to acquisition cohorts
- Calculate retention periods
- Build cohort retention matrix
- Compute retention percentages

### Customer Lifetime Value Analysis

- Calculate Average Order Value (AOV)
- Calculate Purchase Frequency
- Estimate Customer Lifetime Value (CLTV)
- Compare customer segments

- Cohort Retention Heatmap
- Retention Trend Analysis
- Customer Segment Comparison
