# SaaS-E-Commerce-Cohort-Retention-CLTV-Analysis
## Descrisption
Customer retention is one of the most important drivers of long-term business growth. While acquiring new customers requires significant marketing investment, retaining existing customers improves profitability and sustainable revenue generation.

This project focuses on performing Cohort Retention Analysis and Customer Lifetime Value (CLTV) analysis using transactional customer data. The objective is to identify customer retention patterns, measure long-term customer value, and provide data-driven insights that support strategic business decisions.

This project is being developed as part of the Data Analytics Technical Internship.
