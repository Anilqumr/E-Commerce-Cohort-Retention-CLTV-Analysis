# SaaS / E-Commerce Cohort Retention & Customer Lifetime Value (CLTV) Analysis

## 📌 Project Overview

This project is part of the **Infotact Technical Internship Program – Advanced Data Analytics**. The objective is to analyze customer retention behavior using Cohort Analysis and estimate Customer Lifetime Value (CLTV) to provide actionable business insights for improving customer retention and profitability.

The project follows an end-to-end data analytics workflow, including data cleaning, cohort analysis, customer segmentation, visualization, and business recommendations.

---

## 🎯 Project Objectives

- Perform data cleaning and preprocessing.
- Identify customer cohorts based on their first transaction month.
- Build a Cohort Retention Matrix.
- Calculate monthly customer retention rates.
- Estimate Customer Lifetime Value (CLTV).
- Visualize customer retention trends using heatmaps and line charts.
- Generate business insights to improve customer retention.

## 📂 Dataset Information

The dataset contains e-commerce transactional records, including customer purchases, transaction dates, revenue, acquisition channels, and geographic information.

### Dataset Features

| Column | Description |
|---------|-------------|
| order_id | Unique Order ID |
| customer_id | Unique Customer ID |
| transaction_date | Date of Purchase |
| product_category | Product Category |
| quantity | Quantity Purchased |
| unit_price | Price per Unit |
| revenue | Total Revenue |
| signup_date | Customer Registration Date |
| acquisition_channel | Marketing Acquisition Source |
| country | Customer Country |

## 📊 Project Workflow

### Week 1 – Data Cleaning & Preprocessing

- Imported the raw dataset.
- Checked dataset structure.
- Removed duplicate records.
- Handled missing values.
- Converted date columns into datetime format.
- Validated customer and transaction information.
- Prepared the dataset for cohort analysis.

---

### Week 2 – Cohort Retention Analysis

- Generated Cohort Month.
- Calculated Cohort Index.
- Built Cohort Retention Matrix.
- Calculated monthly retention percentages.

---

### Week 3 – Customer Lifetime Value (CLTV)

- Calculated Average Order Value (AOV).
- Calculated Purchase Frequency.
- Estimated Customer Lifetime Value.
- Compared CLTV across customer segments.

---

### Week 4 – Visualization & Insights

- Created Cohort Retention Heatmap.
- Built Retention Trend Charts.
- Analyzed customer churn behavior.
- Generated strategic business recommendations.
